# MI PORTAFOLIO DE PANDAS: Un Viaje de Persistencia

> *"No es perfecto, pero es mío."*

Este repositorio es una colección de código; es la evidencia de semanas de **esfuerzo, frustración y, finalmente, entendimiento**.

Cuando empecé este camino en el análisis de datos con Python, no sabía cuánto me costaría. No voy a mentir: **este proceso me tomó más tiempo de lo que "normalmente" debería**. Hubo días en los que una simple línea de código no funcionaba, errores que parecían no tener sentido y conceptos que tuve que leer tres o cuatro veces para asimilar.

Pero aquí está. Cada función, cada limpieza de datos y cada reporte generado representa una pequeña batalla ganada. Aunque conté con asistencia para guiarme, **la lógica, el aprendizaje y la ejecución son míos**. He pasado de no saber cómo cargar un archivo a construir un sistema completo de nómina automatizado.

Este portafolio documenta esa evolución: desde lo básico hasta la creación de frameworks reutilizables. Es imperfecto, humano y sincero.

---

## 🚀 El Camino Recorrido

El aprendizaje se dividió en tres grandes bloques, cada uno más desafiante que el anterior:

### **Bloque 1: Los Fundamentos**
Aquí fue donde todo comenzó. Entender qué es un DataFrame, cómo se diferencia de una Serie y cómo perder el miedo a ver datos en una terminal en lugar de un Excel.
*   **Logro Clave:** Cargar y explorar mi primer dataset (`employees.csv`).

### **Bloque 2: Selección y Filtrado**
La etapa de "encontrar la aguja en el pajar". Aprendí a no conformarme con todos los datos, sino a extraer solo lo que importa.
*   **Herramientas:** `.loc`, `.iloc`, filtros booleanos y consultas complejas `.query()`.
*   **Highlight:** Un sistema de inventario para una tienda ficticia.

### **Bloque 3: Manipulación y Creación (La "Joya")**
**Lo más difícil y lo más gratificante.**
Aquí dejé de ser un espectador de los datos para convertirme en un creador. No solo leí información; la transformé, la calculé y la enriquecí.
*   **El Reto:** Crear un sistema de nómina real.
*   **La Solución:** No escribí código suelto; construí un "**Framework**" de funciones reutilizables (`salarial_and_others_block`, `concat_values`, etc.) que hacen el trabajo pesado.
*   **Estilo:** El código está escrito y comentado para contar una historia, no solo para ejecutar instrucciones.

## Cuánto tiempo me tomó?

En promedio, cada bloque tomó alrededor de 2 semanas de trabajo. Sin embargo, el Bloque 3, que involucra la creación de un sistema de nómina, tomó más tiempo debido a la complejidad de la tarea y la necesidad de construir un framework reutilizable y bueno, realmente quise hacer algo distintivo y más "profesional".

Así que, si tuviese que dar un tiempo exacto del proceso, diría que fueron alrededor de 4 meses. 

Aún no cubro todo, me faltan muchísimas cosas que cubrir, sin embargo, creo que ya estoy en un buen camino, **al menos para contribuir a este gran mundo**.

## Lo que Sigue

Este portafolio cierra el capítulo de manipulación de datos en Python, pero abre la puerta al siguiente gran desafío: **SQL**.

Me llevo de aquí no solo el código, sino la **resiliencia**. Aprendí que no importa si me toma el doble de tiempo que a otros; lo importante es que, al final, el código corre, los datos hablan y yo entiendo cada coma del script.
